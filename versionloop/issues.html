Versionloop issue tracker

Public list of known bugs, feature requests and their progress for Versionloop: Version & Component Sync for Jira. No sign-in needed. Last updated: 22 November 2026.

Report a bug or ask for a feature: email support@studiowebworks.com. We reply within two working days (Central European Time) and add every confirmed bug and every feature request here, without names, site addresses or other personal data. See also the support and user guide.

Limits by design

These are not bugs; they are explained in the user guide.

  • A follower cannot lead another group, because Jira does not tell an app about changes it made itself, so a chain would not pass changes on.
  • 50 groups per site and 50 followers per group.
  • Only Jira administrators can see the Versionloop page.
